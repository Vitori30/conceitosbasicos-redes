# 🌐 Conceitos Básicos de Redes

Este repositório foi desenvolvido como parte dos meus estudos no curso **Conceitos Básicos de Redes** da Cisco Networking Academy.

O objetivo deste projeto é reunir, de forma organizada, os conteúdos estudados, os laboratórios realizados e as anotações produzidas durante o curso, servindo como registro da minha evolução e como material de consulta para futuras revisões.

## 🎯 Objetivos

- Consolidar os conhecimentos adquiridos durante o curso.
- Praticar a utilização do Git e GitHub.
- Documentar os laboratórios realizados.
- Desenvolver uma organização de projetos voltada para documentação técnica.

## 🛠️ Ferramentas utilizadas

- Cisco Packet Tracer
- Git
- GitHub
- Markdown
