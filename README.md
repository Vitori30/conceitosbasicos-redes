# 🖥️ Laboratórios Desenvolvidos

Durante o curso foram realizados diversos laboratórios utilizando o **Cisco Packet Tracer**, permitindo aplicar na prática os conceitos estudados.

Os laboratórios abordam temas como:

- Configuração de roteadores;
- Configuração de redes locais (LAN);
- Configuração de DHCP;
- Configuração de NAT;
- Identificação de endereços IP e MAC;
- Comunicação entre dispositivos;
- Testes de conectividade utilizando Ping;
- Utilização do comando IPConfig;
- Acesso a servidores Web;
- Serviços de rede.

Cada laboratório contém:

- 🎯 Objetivo
- 📝 Procedimentos realizados
- ⚙️ Configurações aplicadas
- 🖼️ Evidências (imagens)
- ✅ Resultado obtido
