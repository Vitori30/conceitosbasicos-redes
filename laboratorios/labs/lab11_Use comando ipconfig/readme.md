# Lab 10 - Usando o Comando `ipconfig`

## 🎯 Objetivo
Neste laboratório, utilizei o comando `ipconfig /all` para identificar uma configuração incorreta em um computador, analisando os parâmetros de rede e corrigindo o problema de conectividade.

## 📂 Componentes
- 4 PCs
- Servidor Web (www.cisco.pka)
- Cisco Packet Tracer

## ⚙️ Configuração
- Acessei o Prompt de Comando em cada computador.
- Executei o comando `ipconfig /all` para visualizar as configurações de rede.
- Comparei os endereços IP, a máscara de sub-rede e o gateway padrão dos quatro computadores.
- Identifiquei o computador com a configuração incorreta.
- Corrigi as informações na janela **IP Configuration**.

## 🧪 Testes
- Executei o comando `ipconfig /all` em todos os computadores.
- Analisei as configurações de endereço IP.
- Verifiquei a máscara de sub-rede configurada.
- Comparei o gateway padrão de cada equipamento.
- Corrigi a configuração incorreta no computador identificado.
- Confirmei que o computador voltou a se comunicar corretamente com a rede.

## 🛠️ Tecnologias utilizadas
- Cisco Packet Tracer
- IPv4
- Endereçamento IP Estático
- Gateway Padrão
- Command Prompt
- `ipconfig`

## 💡 Habilidades desenvolvidas
- Identificação de configurações incorretas de rede.
- Utilização do comando `ipconfig /all`.
- Análise de endereços IPv4.
- Verificação da máscara de sub-rede e do gateway padrão.
- Correção de configurações de rede em hosts.
- Diagnóstico de problemas de conectividade.

## ✅ Verificação Final
Verifiquei que a utilização do comando `ipconfig /all` permite identificar rapidamente configurações incorretas de endereço IP, máscara de sub-rede e gateway padrão, facilitando a correção de problemas de comunicação entre o computador e a rede.
