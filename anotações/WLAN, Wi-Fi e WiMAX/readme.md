# O que é WLAN?

**WLAN (Wireless Local Area Network)** significa:

**Rede Local Sem Fio**

É uma rede que permite a comunicação entre dispositivos sem utilizar cabos.

Ela é uma versão sem fio de uma LAN tradicional.

Exemplo:

```
Notebook
    │
Celular ─── Wi-Fi ─── Roteador
    │
Smart TV
```

Todos esses dispositivos fazem parte de uma WLAN.

---

# Explicando de forma simples

Imagine uma sala.

Em uma rede cabeada, você precisaria passar cabos para conectar os computadores.

Na WLAN, esses cabos são substituídos por sinais de rádio.

É como se existisse uma "estrada invisível" transportando os dados pelo ar.

---

# Características da WLAN

✔ Comunicação sem fio.

✔ Utiliza ondas de rádio.

✔ Permite mobilidade dos usuários.

✔ Facilita instalação da rede.

✔ Muito utilizada em residências e empresas.

---

# O que é Wi-Fi?

**Wi-Fi** é uma tecnologia que permite conectar dispositivos sem fio através do padrão:

**IEEE 802.11**

Ele é o método mais comum para criar uma WLAN.

Exemplos de dispositivos Wi-Fi:

- Celulares.
- Notebooks.
- Tablets.
- Smart TVs.
- Impressoras sem fio.

---

# Como funciona o Wi-Fi?

O dispositivo se conecta a um:

📡 **Access Point (AP)**

ou

📡 **Roteador Wi-Fi**

Esse equipamento transmite e recebe dados utilizando ondas de rádio.

---

# Frequências do Wi-Fi

## 2.4 GHz

Características:

✔ Maior alcance.

✔ Melhor atravessando paredes.

❌ Menor velocidade.

❌ Mais interferência.

---

## 5 GHz

Características:

✔ Maior velocidade.

✔ Menos interferência.

❌ Menor alcance.

---

## 6 GHz

Utilizada em padrões Wi-Fi mais recentes.

Características:

✔ Mais canais disponíveis.

✔ Maior desempenho.

---

# Padrões Wi-Fi

A tecnologia Wi-Fi evoluiu com diferentes padrões:

| Padrão | Nome popular | Característica |
|---|---|---|
| 802.11b | Wi-Fi antigo | Baixa velocidade |
| 802.11g | Wi-Fi antigo | Melhor desempenho |
| 802.11n | Wi-Fi 4 | Melhor alcance |
| 802.11ac | Wi-Fi 5 | Alta velocidade |
| 802.11ax | Wi-Fi 6 | Mais eficiência |

---

# O que é WiMAX?

**WiMAX (Worldwide Interoperability for Microwave Access)** é uma tecnologia de comunicação sem fio criada para alcançar áreas maiores que o Wi-Fi.

Utiliza o padrão:

**IEEE 802.16**

---

# Explicando de forma simples

O Wi-Fi é como uma rede dentro de uma casa.

O WiMAX é como uma rede que pode atender uma cidade ou uma região maior.

Exemplo:

🏠 Wi-Fi:

Casa → Roteador → Dispositivos

🌎 WiMAX:

Antena → Grandes áreas → Usuários

---

# Características do WiMAX

✔ Grande alcance.

✔ Pode atender áreas rurais.

✔ Utiliza comunicação por micro-ondas.

✔ Pode ser alternativa para locais sem infraestrutura de cabo.

---

# WLAN x Wi-Fi x WiMAX

| Tecnologia | Significado | Função |
|---|---|---|
| WLAN | Rede local sem fio | Tipo de rede |
| Wi-Fi | Tecnologia IEEE 802.11 | Conectar dispositivos sem fio |
| WiMAX | IEEE 802.16 | Comunicação sem fio de longo alcance |

---

# Equipamentos utilizados

## Access Point (AP)

É responsável por fornecer conexão sem fio aos dispositivos.

---

## Roteador Wi-Fi

Combina:

- Roteador.
- Switch.
- Access Point.
- DHCP.
- NAT.

---

# Segurança em redes sem fio

As redes Wi-Fi utilizam mecanismos de proteção como:

- WPA.
- WPA2.
- WPA3.

Esses protocolos ajudam a proteger os dados transmitidos.

---

# Exemplo prático

Na sua casa:

1. O provedor entrega Internet.
2. O roteador recebe essa conexão.
3. O Access Point cria a rede Wi-Fi.
4. O celular conecta usando WLAN.
5. O roteador utiliza DHCP para entregar um IP.
6. O NAT permite acesso à Internet.

---

# Resumo

✅ WLAN é uma rede local sem fio.

✅ Wi-Fi é a tecnologia mais usada para criar WLAN.

✅ Wi-Fi utiliza o padrão IEEE 802.11.

✅ WiMAX utiliza IEEE 802.16 e possui maior alcance.

✅ Redes sem fio utilizam ondas de rádio.

✅ Roteadores Wi-Fi geralmente possuem várias funções integradas.

---

# Curiosidade

Apesar de muitas pessoas usarem "Wi-Fi" e "WLAN" como sinônimos, eles não são exatamente a mesma coisa. WLAN é o conceito da rede sem fio; Wi-Fi é uma tecnologia utilizada para implementar essa rede.
