# O que são cabos de rede?

Os **cabos de rede** são meios físicos utilizados para transportar dados entre dispositivos conectados a uma rede.

Eles permitem a comunicação entre:

- Computadores.
- Switches.
- Roteadores.
- Servidores.
- Impressoras.
- Access Points.

---

# Explicando de forma simples

Imagine uma estrada.

🚗 Os carros representam os dados.

🛣️ A estrada representa o cabo de rede.

Quanto melhor a estrada, maior a quantidade de informações que conseguem passar com qualidade.

Os cabos são o caminho por onde os dados viajam.

---

# Principais tipos de cabos

## 1️⃣ Cabo de Par Trançado

É o cabo mais utilizado em redes locais (**LAN**).

Ele possui pares de fios de cobre trançados para reduzir interferências.

Exemplo:

```
Computador ─── Cabo de rede ─── Switch
```

---

## Categorias do cabo de par trançado

### Cat5e

- Velocidade: até 1 Gbps
- Frequência: 100 MHz
- Muito utilizado em redes domésticas.

---

### Cat6

- Velocidade: até 10 Gbps (em distâncias menores)
- Frequência: 250 MHz
- Melhor proteção contra interferências.

---

### Cat6a

- Velocidade: até 10 Gbps
- Frequência: 500 MHz
- Usado em ambientes profissionais.

---

# Conector RJ-45

O conector mais utilizado em cabos Ethernet é o **RJ-45**.

Ele conecta o cabo de rede aos equipamentos.

Exemplo:

```
Cabo UTP + Conector RJ-45 = Cabo Ethernet
```

---

# Tipos de cabo de par trançado

## UTP (Unshielded Twisted Pair)

Par trançado sem blindagem.

Características:

- Mais barato.
- Mais comum.
- Usado em casas e escritórios.

---

## STP (Shielded Twisted Pair)

Par trançado com blindagem.

Características:

- Maior proteção contra interferências.
- Usado em ambientes com muito ruído elétrico.

---

# 2️⃣ Fibra Óptica

A fibra óptica transmite dados utilizando sinais de luz.

Ela é formada por pequenos filamentos de vidro ou plástico.

---

## Características

✔ Alta velocidade.

✔ Grandes distâncias.

✔ Baixa interferência.

✔ Muito utilizada em empresas e provedores de Internet.

---

## Tipos de fibra

### Fibra Monomodo

- Longas distâncias.
- Maior alcance.
- Muito usada em redes de operadoras.

---

### Fibra Multimodo

- Distâncias menores.
- Mais comum em redes internas.

---

# 3️⃣ Cabo Coaxial

É um cabo composto por um condutor central protegido por uma camada de isolamento.

Foi muito utilizado em redes antigas.

Hoje é mais comum em:

- Televisão a cabo.
- Sistemas de vídeo.
- Algumas aplicações específicas.

---

# Cabo Direto x Cabo Cruzado

## Cabo Direto (Straight-through)

Usado para conectar dispositivos diferentes.

Exemplos:

```
Computador → Switch

Switch → Roteador
```

---

## Cabo Cruzado (Crossover)

Usado para conectar dispositivos semelhantes.

Exemplos:

```
Computador → Computador

Switch → Switch
```

Atualmente muitos equipamentos possuem **Auto-MDI/MDIX**, fazendo essa identificação automaticamente.

---

# Padrões de montagem

Os cabos Ethernet utilizam padrões de cores:

## T568A

Organização dos fios em uma sequência específica.

## T568B

O padrão mais utilizado atualmente.

---

# Comparação dos cabos

| Tipo | Característica |
|---|---|
| UTP | Mais usado, baixo custo |
| STP | Mais proteção contra interferências |
| Fibra Óptica | Maior velocidade e distância |
| Coaxial | Tecnologia mais antiga |

---

# Como escolher um cabo?

Depende de:

📌 Distância que o cabo precisa percorrer.

📌 Velocidade necessária.

📌 Ambiente de instalação.

📌 Quantidade de interferência.

📌 Custo disponível.

---

# Exemplo prático

Em uma casa:

```
Computador
     │
     │ Cabo Cat6
     │
Roteador
     │
Internet
```

O cabo permite que os dados sejam enviados entre o computador e o equipamento de rede.

---

# Resumo

✅ Cabos de rede transportam dados.

✅ Ethernet utiliza principalmente cabos de par trançado.

✅ RJ-45 é o conector mais comum.

✅ UTP é o cabo mais utilizado.

✅ Fibra óptica oferece maior velocidade e distância.

✅ Cat6 é muito utilizado atualmente.

✅ A escolha do cabo depende da necessidade da rede.

---

# Curiosidade

Apesar do crescimento das redes sem fio (Wi-Fi), os cabos de rede continuam sendo muito utilizados em empresas, servidores e equipamentos críticos porque oferecem maior estabilidade, menor latência e mais segurança na transmissão dos dados.
