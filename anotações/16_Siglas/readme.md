# 📚 Principais Siglas e Significados

## 🌐 Modelos e padrões

### OSI
**Open Systems Interconnection**

📌 Modelo de referência que divide a comunicação de rede em 7 camadas.

---

### TCP/IP
**Transmission Control Protocol / Internet Protocol**

📌 Modelo utilizado na Internet para comunicação entre dispositivos.

---

### IEEE
**Institute of Electrical and Electronics Engineers**

📌 Organização responsável por criar padrões de tecnologia.

Exemplo:

- IEEE 802.3 → Ethernet
- IEEE 802.11 → Wi-Fi

---

### RFC
**Request for Comments**

📌 Documentos que definem padrões e protocolos da Internet.

---

# 📍 Endereçamento

## IP
**Internet Protocol**

📌 Protocolo responsável pelo endereçamento e envio de pacotes.

---

## IPv4
**Internet Protocol version 4**

📌 Versão do protocolo IP com 32 bits.

Exemplo:

```
192.168.1.10
```

---

## IPv6
**Internet Protocol version 6**

📌 Nova versão do IP com 128 bits.

Exemplo:

```
2001:db8::1
```

---

## MAC
**Media Access Control**

📌 Endereço físico da placa de rede.

Exemplo:

```
00:1A:2B:3C:4D:5E
```

---

## DNS
**Domain Name System**

📌 Sistema que transforma nomes de sites em endereços IP.

Exemplo:

```
google.com → endereço IP
```

---

## DHCP
**Dynamic Host Configuration Protocol**

📌 Protocolo que entrega automaticamente:

- IP
- Máscara
- Gateway
- DNS

---

# 🖥️ Equipamentos

## NIC
**Network Interface Card**

📌 Placa de rede responsável pela conexão do dispositivo.

---

## AP
**Access Point**

📌 Equipamento que fornece conexão sem fio.

---

## ISP
**Internet Service Provider**

📌 Provedor de serviço de Internet.

Exemplo:

Empresas que fornecem acesso à Internet.

---

## CPE
**Customer Premises Equipment**

📌 Equipamento instalado no cliente pelo provedor.

Exemplo:

Roteador residencial.

---

# 🌎 Tipos de Redes

## LAN
**Local Area Network**

📌 Rede local.

Exemplo:

Rede de uma casa ou empresa.

---

## WAN
**Wide Area Network**

📌 Rede de longa distância.

Exemplo:

Internet.

---

## MAN
**Metropolitan Area Network**

📌 Rede que cobre uma cidade ou região metropolitana.

---

## WLAN
**Wireless Local Area Network**

📌 Rede local sem fio.

Exemplo:

Wi-Fi.

---

## PAN
**Personal Area Network**

📌 Rede pessoal de curto alcance.

Exemplo:

Bluetooth.

---

## VPN
**Virtual Private Network**

📌 Rede privada virtual que cria uma conexão segura.

---

# 🔗 Protocolos

## TCP
**Transmission Control Protocol**

📌 Protocolo confiável que garante entrega dos dados.

---

## UDP
**User Datagram Protocol**

📌 Protocolo mais rápido, mas sem garantia de entrega.

---

## HTTP
**HyperText Transfer Protocol**

📌 Protocolo usado para acessar páginas Web.

Porta:

```
80
```

---

## HTTPS
**HyperText Transfer Protocol Secure**

📌 Versão segura do HTTP.

Porta:

```
443
```

---

## FTP
**File Transfer Protocol**

📌 Transferência de arquivos.

---

## SSH
**Secure Shell**

📌 Acesso remoto seguro.

Porta:

```
22
```

---

## SMTP
**Simple Mail Transfer Protocol**

📌 Envio de e-mails.

---

# 🔐 Segurança

## NAT
**Network Address Translation**

📌 Traduz endereços IP privados em públicos.

---

## ACL
**Access Control List**

📌 Lista de regras que controla acessos na rede.

---

## SSL
**Secure Sockets Layer**

📌 Tecnologia antiga de segurança para comunicação.

---

## TLS
**Transport Layer Security**

📌 Protocolo atual usado para criptografar comunicações.

---

# 🔧 Cisco

## IOS
**Internetwork Operating System**

📌 Sistema operacional dos equipamentos Cisco.

---

## CLI
**Command Line Interface**

📌 Interface de linha de comando utilizada para configurar equipamentos.

---

## VLAN
**Virtual Local Area Network**

📌 Cria redes virtuais dentro de uma mesma rede física.

---

## STP
**Spanning Tree Protocol**

📌 Evita loops em redes com switches.

---

## PoE
**Power over Ethernet**

📌 Permite transmitir energia e dados pelo mesmo cabo de rede.

---

| DHCP | Dynamic Host Configuration Protocol | Entrega IP automático |
| TCP | Transmission Control Protocol | Comunicação confiável |
| UDP | User Datagram Protocol | Comunicação rápida |
| NAT | Network Address Translation | Tradução de endereços |
| LAN | Local Area Network | Rede local |
| WAN | Wide Area Network | Rede ampla |
| WLAN | Wireless LAN | Rede sem fio |
| VPN | Virtual Private Network | Conexão segura |
