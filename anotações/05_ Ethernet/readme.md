# O que é?

**Ethernet** é a tecnologia mais utilizada para conectar dispositivos em uma **rede local (LAN)** por meio de cabos.

Ela define como os dados são enviados, recebidos e organizados entre computadores, switches, roteadores e outros dispositivos conectados à mesma rede.

---

# Explicando de forma simples

Imagine uma rua.

🚗 Os carros representam os dados.

🛣️ A rua representa o cabo de rede.

🚦 As regras de trânsito representam a Ethernet.

Assim como os carros precisam seguir regras para evitar acidentes, os dispositivos utilizam a Ethernet para que os dados sejam enviados corretamente.

---

# Como a Ethernet funciona?

Quando um computador deseja enviar uma informação:

1. Os dados são organizados em **quadros (frames)**.
2. O quadro recebe o endereço **MAC** de origem e destino.
3. O quadro é enviado pelo cabo de rede.
4. O switch identifica o MAC de destino.
5. O quadro chega ao dispositivo correto.

---

# Camadas do Modelo OSI

A Ethernet atua em duas camadas:

## Camada 1 – Física

Responsável pela transmissão dos bits através do cabo.

Exemplos:

- Cabo de rede
- Conectores RJ-45
- Fibra óptica

---

## Camada 2 – Enlace

Responsável por:

- Criar os quadros (Frames)
- Utilizar o endereço MAC
- Detectar erros
- Controlar a comunicação na rede local

---

# Meios de transmissão

## Cabo de par trançado (UTP)

É o mais utilizado em residências e empresas.

Exemplo:

Cabo Cat5e

Cabo Cat6

Cabo Cat6a

---

## Fibra óptica

Utiliza luz para transmitir dados.

Vantagens:

- Alta velocidade
- Grandes distâncias
- Não sofre interferência elétrica

---

## Cabo coaxial

Muito utilizado nas primeiras redes Ethernet.

Hoje é pouco utilizado em redes locais.

# Velocidades da Ethernet

| Padrão | Velocidade |
|--------|------------|
| Ethernet | 10 Mbps |
| Fast Ethernet | 100 Mbps |
| Gigabit Ethernet | 1 Gbps |
| 10 Gigabit Ethernet | 10 Gbps |

Quanto maior a velocidade, mais rapidamente os dados podem ser transmitidos.

# Ethernet x Wi-Fi

| Ethernet | Wi-Fi |
|----------|--------|
| Usa cabo | Usa ondas de rádio |
| Mais estável | Pode sofrer interferências |
| Menor latência | Maior latência |
| Mais rápida | Depende da distância e dos obstáculos |

# Curiosidade

A Ethernet foi desenvolvida na década de 1970 pelo engenheiro **Robert Metcalfe**. Desde então, tornou-se o padrão mais utilizado para comunicação em redes locais devido à sua confiabilidade, simplicidade e alta velocidade.
